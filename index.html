Two small pieces for people who run their own metal. Use either on its own — together they replace a whole platform.

HopOS
The Go-only OS

An operating system that is only your application: no Linux, no containers, no kernel in front of the hardware. By default every app gets whole cores behind a silicon cage — on ARM and RISC-V, from a €10 board to a 128-core server.

read the HopOS story →
HOP
The orchestrator

A single binary that runs everything — processes, containers, and whole machines on HopOS. Leader, agent and API in one process; state in any S3 bucket.
